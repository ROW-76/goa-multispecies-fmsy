Case study, advanced population modelling

Multi-species FMSY for Gulf of Alaska groundfish

Rceattle (TMB) Pollock, cod, arrowtooth flounder Projection 2018 to 2100

Fishing mortality that produces maximum sustainable yield, FMSY, can be solved directly for a single species. It cannot be solved directly once species prey on each other. This project calculates a multi-species FMSY for three interacting Gulf of Alaska groundfish by fitting the Rceattle model and projecting it forward to ecological equilibrium.

Why the analytical method fails here

Arrowtooth flounder eats both pollock and cod. Cod eats pollock. Pollock cannibalizes its own juveniles. Because each species' natural mortality depends on the abundance of the others, the system has no closed-form solution. FMSY has to be found numerically: fit the model to historical data, then project it forward under a constant fishing mortality until every species settles into equilibrium.

Model fitting

Rceattle was fit in three stages using GOA groundfish assessment data from 1977 to 2018: single-species, single-species with estimated natural mortality, then full multi-species with estimated predation mortality (M2). All models converged, with final gradients below 0.001.

Harvest control rules tested

Each rule defines a different optimization target inside the model, then the optimizer solves for the constant fishing mortality that satisfies it.

Results

Constrained CMSY is the only rule that both maximizes catch and holds every species above a biological floor. It defines this study's multi-species FMSY.

Findings

  • Unconstrained catch maximization collapses the system. Without a biomass floor, the optimizer drives all three species toward zero.
  • One constraint fixes it. Adding a 35% SSB floor turns the same objective into a stable equilibrium by 2100.
  • Constrained FMSY runs 17 to 43% higher than F40, highest for arrowtooth, lowest for pollock, because the 35% floor permits lower equilibrium biomass than F40's 40% target.
  • An 82-year projection is long enough. Fishing mortality variance across 2091 to 2100 is on the order of 10-27 for every species.
  • The single-species per-recruit shortcut was checked and ruled out. It runs correctly but ignores predation entirely, confirming the numerical approach is necessary.

Code

Every harvest control rule sets a different penalty term inside the model's objective function. The constrained CMSY rule looks like this:

ms_run_concmsy <- Rceattle::fit_mod(
  data_list = GOA2018SS,
  inits = ss_run_M$estimated_params,
  HCR = build_hcr(
    HCR = 1, // catch maximization
    Plimit = 0.35 // biomass floor
  ),
  msmMode = 1, suitMode = 0, niter = 3
)
